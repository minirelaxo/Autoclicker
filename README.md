# Nova Autoclicker- hallo lasse

Ein selbst entwickeltes Autoclicker-Projekt mit dem Ziel, einen besseren und
einfach zu bedienenden Autoclicker zu bauen.

## Über das Projekt

Nova Autoclicker wird Schritt für Schritt entwickelt. Das Projekt nutzt Python
für die Anwendung, Tkinter für die grafische Oberfläche und PyAutoGUI für
Mausaktionen. Darüber hinaus werden weitere Bibliotheken verwendet.

**Das Projekt befindet sich noch in Entwicklung.** Viele Funktionen eines
fertigen Autoclickers sind noch nicht implementiert.

## Voraussetzungen

- Python 3
- PyAutoGUI
- Tkinter

Installiere PyAutoGUI bei Bedarf mit:

```bash
python -m pip install pyautogui
```

## Starten

Starte das Programm im Projektordner mit:

```bash
python main_Window.py
```

## Entwicklungsziele

- Eine übersichtliche und leicht bedienbare Oberfläche
- Klicks komfortabel starten und stoppen
- Einstellungen für das Klickverhalten

## Hinweis

Dieses Projekt ist ein persönliches Lern- und Entwicklungsprojekt. Funktionen
und Bedienung können sich während der Entwicklung noch ändern.
